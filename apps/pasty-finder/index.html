Where the data comes from

Built-in list works with no signal. Scans pull live, surveyed data over the top.

Built-in Cornwall list Locations are town-level approximations and opening hours are indicative patterns, not published times — both marked in the UI. No star ratings are invented.
OpenStreetMap — free, no key Sweeps every bakery and pasty shop mapped in Cornwall. Real coordinates, real published opening hours, phone and website. No reviews.
Google Places — your own key The only source with star ratings and review counts — and real photographs of each shop. Your key stays in this browser and is sent only to Google.
How to get a key (about three minutes, free tier)
  1. Open console.cloud.google.com and create a project.
  2. Enable Places API (New) under APIs & Services.
  3. Credentials → Create credentials → API key.
  4. Restrict it to the Places API. The free monthly allowance covers holiday use comfortably.
  5. Paste it above — stored in this browser only.
